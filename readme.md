This project is developed using Python 3.12.5. It analyzes the constituent of the Taiwan Top 50 ETF (0050) and aimes to identify potentially profitable stocks by calculating their Bollinger Bands.The selected stocks and their Bollinger Bands are then saved to an Excel file, which can serve as a reference for investment planning.

# Requirements

* Python 3.12.5 (or above)
* yfinance library
* pandas library
* openpyxl library for Excel export
